        How it works

        The resilience cycle behind the dashboard

        1. Anticipate: the top challenges and their likelihood × impact.
        2. Monitor: 24 KPIs with a target, an owner and a trend.
        3. Respond: track & trace every incident, timed against a recovery target.
        4. Learn: every incident ends with a lesson, and often a new KPI.
        5. Rehearse: stress tests show weak spots before a real crisis does.

        Where the data would come from

          Built with an LLM

          • Built with Claude (Anthropic) for the LDD class on resilience, within the 2-hour limit.
          • Steps: brief → resilience challenges → KPIs and targets → page → live test.
          • Plain HTML, CSS and JavaScript. Live reports run on a free Supabase database.
          • All KPI values are demo data, chosen to be realistic. They are not official Hotelschool figures.
